# Fibonacci Project

## Описание
Программа генерирует первые `n` чисел последовательности Фибоначчи.

## Сборка и запуск
```bash
mkdir build
cd build
cmake ..
make
./Fibonacci          # Запуск основного приложения
./UnitTests          # Запуск Unit-тестов
```

## Зависимости
- CMake >= 3.10
- Компилятор с поддержкой C++98
- Google Test

## Инструкция по сборке и тестированию
1. Перейдите в корень проекта и выполните команды:
```bash

```
3. Запуск тестов:
